# My Useful Websites & Tools Directory

A curated list of useful websites for AI, UI/UX design, photo editing, graphics, icons, image compression, and online tools.

---

## 🤖 AI Tools

- **[Gemini](https://gemini.google.com)**  
  - *Description:* Google's AI assistant for writing, brainstorming, analysis, and problem-solving.

- **[ChatGPT](https://chatgpt.com)**  
  - *Description:* AI chatbot used for generating prompts, ideas, code, and content creation.

- **[Google AI Studio](https://aistudio.google.com)**  
  - *Description:* Web-based prototyping environment for experimenting and building with Gemini models.

- **[Google Imagen](https://deepmind.google/technologies/imagen/)**  
  - *Description:* Advanced AI image generation model used for creating high-quality visual content.

- **[Adobe Firefly](https://firefly.adobe.com)**  
  - *Description:* Generative AI tool for creating artwork, text effects, and image editing.

- **[Microsoft Designer](https://designer.microsoft.com)**  
  - *Description:* AI-powered graphic design app for creating social media posts, invitations, and graphics.

---

## 🎨 UI/UX & Graphic Design

- **[Figma](https://www.figma.com)**  
  - *Description:* Collaborative interface design tool for website, UI/UX, and vector design.

- **[Photopea](https://www.photopea.com)**  
  - *Description:* Advanced web-based image editor that supports Photoshop (PSD) files.

- **[Pattern Monster](https://patternmonster.org)**  
  - *Description:* SVG pattern generator to create custom, repeatable background patterns.

- **[Adobe Express](https://www.adobe.com/express/)**  
  - *Description:* Tool used for photo editing, optimization, and graphics design.

- **[Freepik](https://www.freepik.com)**  
  - *Description:* Download professional stock images and 3D vector cartoons.

- **[Vecteezy](https://www.vecteezy.com)**  
  - *Description:* Resource for vector files and high-quality images.

- **[Canva](https://www.canva.com)**  
  - *Description:* Used for designing website banner backgrounds.

## 🎯 Icons

- **[Flaticon](https://www.flaticon.com)**  
  - *Description:* Database for creating and finding custom duotone icons.

- **[Icons8](https://icons8.com)**  
  - *Description:* Search engine and repository for various styles of icons.

- **[Feather Icons](https://feathericons.com)**  
  - *Description:* Simply beautiful open-source SVG icons for professionals.

## 🛠️ Color & Compression Tools

- **[Make Tints and Shades](https://maketintsandshades.com)**  
  - *Description:* Useful for getting different shades and tints of any hex color code.

- **[ImageCompressor.com](https://imagecompressor.com)**  
  - *Description:* Used to reduce image file size effectively.

- **[Reduce Images](https://www.reduceimages.com)**  
  - *Description:* Online tool to resize, reduce resolution, and compress images.
